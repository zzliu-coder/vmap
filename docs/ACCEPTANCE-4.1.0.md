# v4.1.0 会安古城增量验收 · 2026-09-25

## 本轮范围

- 保留原 203 条越南米其林相关地点记录，不修改原记录字段。
- 新增城市“会安古城 / Hội An”。
- 新增 11 个会安古城周边餐饮与饮品点，均明确标注为非米其林本地口碑补充。
- 2026 越南米其林官方覆盖城市仍为河内、胡志明市、岘港；不把会安地点冒充米其林入选。
- 新点位保存独立来源、OpenStreetMap 坐标来源、参考价格日期；能核到的门店保存 Google Place ID。

## 新增类型

高楼面、白玫瑰、会安鸡饭、会安法棍、米纸卷/越南煎饼套餐、综合本地菜、现代越南/亚洲小盘、草本饮。

## 验收标准

- 主数据应为 214 条；其中 200 条有公开坐标、14 条保持不上图。
- 会安应有 11 条且全部有公开坐标；其 awards 为空对象。
- 原 VN001–VN203 数据与上一发布提交逐字段一致。
- 新地点坐标只使用有明确 OpenStreetMap 对象来源的公开点位，不用城市中心替代。
- 价格均标记为旅行预算估算，个别有公开菜单价的地点另记录 menuSource 和说明。
- 网站城市下拉框自动出现“会安古城”，地图可显示 11 个点。
- Google Maps 跳转按门店名、地址及已核到的 Place ID 生成；未开通付费 Google Places API。

## 限制

公开坐标并非现场测量，店门口、车辆入口、营业状态和现场价格仍需出发前核对。
会安口碑点依据公开资料与近期评价筛选，不构成米其林评价或官方推荐。
