# v4.2.0 定位坐标与旅行日记验收 · 2026-09-25

## 本轮新增

- 定位成功后直接显示纬度、经度和浏览器返回的定位精度。
- “复制经纬度”只复制 `纬度,经度`，便于直接发给 ChatGPT 查询周边。
- 地点详情增加“在这里打卡”；定位区增加“当前位置打卡”。
- 打卡记录包含时间、地点、备注、坐标来源以及最多 8 张照片。
- 图片优先压缩到最长边 1600px、JPEG 0.84；不支持压缩时保留原图。

## 本地存储与导出

- 打卡记录和照片使用浏览器 IndexedDB，仅保存在当前站点/当前浏览器。
- 支持编辑记录、继续追加照片、删除记录。
- 支持导出带照片的独立旅行日记 HTML。
- 支持导出 JSON 完整备份，并在同一应用中重新导入。
- 页面会显示打卡数量、照片数量和浏览器存储占用估算。
- 清除网站数据、卸载浏览器或更换设备可能丢失记录，因此界面明确提示定期备份。

## 与定位数据的边界

- 实时 GPS 仍不写入 localStorage/sessionStorage。
- 只有用户主动“打卡”时，才把当时的坐标快照写入 IndexedDB。
- 有真实 GPS 时记录 GPS；手动地图位置明确标记为“地图临时位置”。
- 未定位但在已有地点详情打卡时，只保存该地点公开坐标，并标记为“地点公开坐标”，不冒充现场 GPS。
- 经纬度复制保留 6 位小数；精度单独显示，不混入复制文本。
