## 验收边界

手机 GPS 与剪贴板在隔离无头 Chrome 内使用模拟值，不代表在用户安卓手机上实际定位或复制。
没有打开用户登录态、没有在 Grab 内实际搜索、订车、付款或发送消息。
公共坐标的门店入口与车辆可到达入口仍需逐家核对；地点码只编码现有坐标。
Google 照片/评价使用跳转入口，未接付费 Places API。多数门店尚无专用分享链接或 Place ID，查询结果仍需核对分店。
现有价格、年度和坐标来源沿用 v3，此次没有重新核实203家的营业、价格和地理信息。
线上部署结果应与推送后 GitHub 的 Vercel 状态及生产网页返回内容共同核验，不以本机通过代替上线成功。
