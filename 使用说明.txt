越南随行地图 v4.0.0 · 2026-09-25

打开 GitHub 仓库已连接的 Vercel 网址，刷新后标题应显示 v4.0.0。
日常不需要下载HTML文件，也不需要再创建新的 Vercel Drop 项目。

默认先看大地图。顶部“筛选”和底部“地点列表”可独立展开与收起；“清屏”显示更大的地图，右上角“恢复面板”返回。
“看我附近”显示当前位置直线5公里内的已收录地点。可在筛选中调整范围；本页没有自动收录清单以外的全部商家。
点击地点 → Google Maps 看照片/评价 → 核对分店 → 复制 Grab 地点码 → 粘贴到 Grab 目的地 → 核对终点图钉与入口 → 再叫车。
Grab 地点码只复制完整代码。店名和街道地址也可以独立复制。代码按公开坐标生成，未逐家实测入口；不要省略最后的核对。
“想去”保存在当前浏览器，关闭网页不会自动同步到其他设备。详情和筛选在当前浏览器会话中保留。
“复制地点信息/反馈”可以把稳定地点ID、门店资料与链接发给我，用于修正或补充。

原203家餐厅全部保留，其中189家有公开坐标，14家暂不上图。年度、估算人均、官方套餐说明和来源均在详情中。
本轮没有擅自加入新景点。其他城市、景点、咖啡、住宿、购物、交通等可按后续需求增量添加。
新点位主数据为 data/places.json；城市列表为 data/cities.json。维护流程见 README.md 和 docs/POINTS.md。
Google 照片在 Google Maps 内查看。本轮未开通 Google Places 付费接口，也未添加 API 密钥。

网页定位仅在浏览器内计算，GPS坐标和轨迹不保存到本地存储或上传至本项目。底图服务器会收到所浏览区域的瓦片请求。
部分餐厅处于酒店、商场或小巷内；地图位置与车辆入口可能不同。营业、分店、价格和车行入口请出发前核对。
距离为直线距离。价格多为旅行预算估算，官方套餐也需另核午晚餐、税费和饮品。
数据署名、许可证及限制见 README.md。旧餐厅真实坐标.csv 和检查记录.json 保留为 v3 历史快照。
